ИНВЕНТАРИЗАЦИЯ — C# / WPF (.NET 10)

Проект собирает автономный Windows EXE через GitHub Actions. Локально устанавливать Python или .NET SDK не нужно.

СБОРКА
1. Создайте на GitHub приватный репозиторий.
2. Загрузите всё содержимое этой папки, включая .github/workflows/build.yml.
3. Commit changes.
4. Откройте Actions → Build Inventar EXE → Run workflow.
5. После успешной сборки откройте запуск и скачайте Artifact Inventar-Windows-EXE.
6. Распакуйте ZIP. Внутри будет Inventar.exe.

РАБОТА
- Выберите .xlsx-файл.
- Программа читает все листы: артикул A, название D, остаток N.
- Повторяющиеся артикулы пропускаются (первое вхождение).
- Пустой остаток считается 0.
- Один скан + Enter = одна единица факта.
- Поиск, отмена последнего скана / Ctrl+Z, звук.
- Автосохранение и восстановление сессии.
- Итоги и CSV-отчёт.

ПРИМЕЧАНИЯ
- Это новая реализация основных функций инвентаризации, а не модификация закрытого исходного кода старого EXE.
- На данном этапе сканирование принимается в поле ввода; глобальный перехват клавиатуры без фокуса пока не реализован.
- При первом тесте проверьте корректность чтения именно вашего прайса и работу сканера.
- EXE не подписан сертификатом. Корпоративные политики могут блокировать его; при запрете обратитесь к IT-службе, не отключая защиту.
